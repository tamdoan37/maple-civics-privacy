| Page | URL | Use it for |
|---|---|---|
| Support (`index.html`) | https://tamdoan37.github.io/maple-civics-privacy/ | App Store **Support URL**, Play **Website** |
| Privacy (`privacy.html`) | https://tamdoan37.github.io/maple-civics-privacy/privacy.html | App Store and Google Play **Privacy Policy URL** |
| Privacy, French (`privacy-fr.html`) | https://tamdoan37.github.io/maple-civics-privacy/privacy-fr.html | French store listings |

## Publishing (GitHub Pages)
1. The repository is public; the pages are plain HTML at the root of `main`
   (`.nojekyll` turns off Jekyll).
2. **Settings → Pages → Build and deployment**: Source **Deploy from a branch**,
   Branch **main**, folder **/ (root)** → **Save**.
3. Wait up to 10 minutes, then use **Visit site** on the same page.
4. Pages only publishes after someone with admin rights and a verified email
   has pushed to `main`, so merge changes yourself on GitHub.

## Updating
Edit the HTML, change the "Last updated" date in both languages, and merge to
`main`. Keep it in step with `docs/privacy.html` in the app repository.
